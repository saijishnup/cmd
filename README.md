## Prerequisites

### Operating System: Windows

**Required:**
- **Git Bash** (pre-installed with Git for Windows)
  - Download from: [git-scm.com](https://git-scm.com/)

**Why Git Bash?**
- Command Prompt (CMD) has some syntax differences
- Git Bash uses standard Unix/Linux commands

### Setup Instructions

1. **Install Git for Windows** (if not already installed)
   - Download from [git-scm.com](https://git-scm.com/)
   - Run the installer with default settings
   - Git Bash will be installed automatically

2. **Verify Installation**
   ```bash
   git --version
   bash --version
   ```

3. **Launch Git Bash**
   - Right-click in any folder → "Git Bash Here"
   - Or search for "Git Bash" in Windows Start Menu

## Quick Reference

### Navigation Commands
- `pwd` - Show current directory
- `cd <directory>` - Change directory
- `ls` - List directory contents
- `clear` - Clear terminal screen

### File Operations
- `touch <filename>` - Create a file
- `cat <filename>` - View file contents
- `echo "text" > <filename>` - Write to file
- `echo "text" >> <filename>` - Append to file

### Directory Operations
- `mkdir <dirname>` - Create directory
- `rmdir <dirname>` - Remove empty directory
- `rm -r <dirname>` - Remove directory with contents
- `mv <source> <destination>` - Move/rename
- `cp -r <source> <destination>` - Copy recursively
